# Sicherheitslücken melden

Bitte **nicht** als öffentliches Issue melden. Nutzt den privaten Meldeweg von GitHub:
Reiter **Security → Report a vulnerability** in diesem Repository.

Besonders interessiert mich alles, was dazu führen könnte, dass

- Mandatsdaten den lokalen Rechner auf anderem Weg verlassen als über das Sprachmodell und das Portal,
- der Ausfüller ohne menschliche Freigabe herunterlädt, eine Warnung quittiert oder das Prozessgericht wählt,
- eine EDA-Datei nach dem Download verändert wird.

Ich melde mich in der Regel innerhalb weniger Werktage.
